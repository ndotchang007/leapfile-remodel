Security

Security information

LeapFILE implements several layers of security to ensure confidentiality during the file transfer process. Each layer reinforces the others to protect data, authenticate users, enforce granular access, and produce a detailed audit trail.

Protection layer

The first layer of security protects data in custody from unauthorized access — the foundation for controlling access to information by blocking all access points.

1. Physical access control

Physical access to systems containing confidential files is controlled and monitored. The service is housed in state-of-the-art data centers featuring 24×7 guarded access facilities using video surveillance and advanced biometric access technologies.

2. Network access control

Network access to systems is highly restricted. Firewalls shield servers from the Internet, restricting access to HTTPS (443) ports only.

3. Data encryption

Data transmissions over any network are always encrypted. Files are uploaded and downloaded using SSL encryption. Data at rest is encrypted at the disk level using AES-256.

4. Data retention

The system enforces a strict data retention policy. Each file transfer contains an expiration date ranging from 1 to 14 days. Undownloaded files are permanently deleted at expiration. Successfully downloaded files are deleted after 8 hours. Users can cancel transfers and delete associated files at any time.

Authentication layer

Security measures validate user identity before granting access. There are two types of users: internal users with LeapFILE accounts and external users who exchange files with internal users.

5. Internal user authentication

Each internal user is assigned a unique ID and password. Passwords must be at least 8 characters with uppercase, lowercase, and a number. Passwords are encrypted to ensure integrity.

6. External user / receiver authentication

Each file transfer carries its own authentication requirements. To download, the receiver must provide a secure download link or tracking code, the matching receiver email address, and optionally an access code set by the sender.

Authorization & audit layers

7. Authorization layer

Each user must authenticate to start a session every time they use the service. User credentials are compared against permissions for every request, enforcing access at the application level.

8. Audit layer

The audit layer records the time, IP address, and user name for every file download. This is compiled for every transfer and made available for tracking file custody. Senders receive an email alert when files are successfully downloaded.
