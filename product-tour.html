Send and receive files

  • Send with web client — just login and select new transfer
  • Send with your Outlook plug-in — compose an email and click LeapFILE Send Attachments
  • Send with the desktop client — right-click the tray icon and select New Transfer
  • Receive files via your file exchange — clients use Secure Upload to send files back
  • Get confirmation for all sent transfers with detailed email notifications

Set up your file exchange site

  • Brand your file exchange site with your logo and custom messaging
  • Clients can directly send files to you with Secure Upload
  • Match your file exchange to your website with custom HTML branding

Organize with repositories & portals

  • Create repositories for each of your teams
  • Add files and folders for your team to access
  • Save transfers from your clients and team
  • Centrally manage all your client files
  • Export all files to an Excel spreadsheet for easy viewing
  • Send files securely to clients out of your portal

Manage files and users

  • Add, bulk import, and disable users from your account page
  • Grant administrator account access
  • Customize user send and receive file options
  • Choose file delivery email options
  • Set default incoming and outgoing transfer delivery windows
  • Define when transfers will be permanently deleted
